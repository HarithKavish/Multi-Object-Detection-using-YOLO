# TensorFlow.js Browser Demo

This directory contains the browser-based demo for the custom CNN classifier, using TensorFlow.js. 

- `index.html`: Main demo page for GitHub Pages or static hosting.
- Loads the model from the Hugging Face model repo.

## Usage
Open `index.html` in your browser or deploy this folder to GitHub Pages.

## Model URL
The model is loaded from:
https://huggingface.co/harithkavish/SkinNet-Analyzer/resolve/main/tfjs_model/model.json
